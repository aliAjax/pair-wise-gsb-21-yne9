# hxwl-07 适航指令执行期限台账

按适用构型匹配机队，管理适航指令的执行期限、完成登记与独立复核。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 功能

- **机队台账**：每架飞机登记型号、序列号、改装状态、当前飞行小时；新飞机登记后自动按现行指令适用构型生成待办
- **指令导入**：写明适用构型（型号 + 改装批次）、日历到期日、飞行小时门槛；达到任一条件即列为待执行
- **构型匹配**：构型不匹配的飞机不进待办，「排除说明」页可查看具体排除原因
- **幂等导入**：同编号同版次重复导入不生成第二份待办；仅为新登记且适用的飞机补建
- **换版管理**：导入更高版次后旧版标记换版、旧记录仍可查，只对尚未执行的飞机按新版重算期限
- **完成与复核**：执行人登记完成时刻；复核人须为未参加本次工作的放行人员（系统强制校验），记录复核依据与复核时刻
- **待补区**：材料不齐的任务留在待补区并记录说明，材料补齐后恢复办理
- **本机留档**：全部数据存 localStorage，刷新可接着办理；支持导出 / 导入 JSON 留档
