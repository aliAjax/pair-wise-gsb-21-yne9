# hxwl-07 适航指令执行期限台账

按适用构型（机型 + 改装批次）管理适航指令（AD）的执行期限与闭环。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 功能

- **机队台账**：登记型号、序列号、改装批次、当前飞行小时；更新小时自动重算未闭环记录期限
- **指令库**：指令写明适用构型、日历到期日、飞行小时门槛；达到任一条件即列待执行
- **导入幂等**：同编号同版次重复导入自动忽略，不生成第二份待办
- **换版**：同编号更高版次导入后，旧记录封存留档可查，仅对尚未执行的飞机重算期限
- **闭环流程**：报完成 → 未参加本次工作的放行人员复核（记录依据与完成/复核时刻）→ 材料不齐留在待补区
- **排除说明**：构型不匹配的飞机不进待办，可在“排除与档案”查看排除原因
- **本机留档**：改动自动存入 localStorage，可导出 / 恢复 JSON 留档接着办理
